## Goal, path and ownership

The Operate warning banner displays a bounded visual summary of the newest severity 0–4 message already present in the selected-autopilot `VehicleState.statusTexts` list. At Compose font scale 1.8 or higher, it allows four text lines and lets the age/navigation footer wrap. Its click action is labeled `Open warning history` for accessibility. The focused `diagnostics/warnings` view stacks its warning filter and search action at that scale; the ordinary route and smaller-scale layout keep their prior behavior. The full message remains available in the existing history. The banner, filter and search change presentation only; the list remains in memory, capped at 50 by the repository, and no new network, persistence, dependency, permission or command path was added.
