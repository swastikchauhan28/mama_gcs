## Input-to-display path and decision

MapLibre supplies the current visible geographic bounds. `OfflineFieldMaps.state` supplies persisted region bounds and native completeness. `VehicleMap` retains the existing center and zoom checks, then passes only complete region bounds to `OfflineViewportCoverage`. This pure helper clips rectangles to the viewport, splits it at each relevant longitude edge and requires latitude intervals to span every strip. A missing strip or latitude interval leaves the warning visible. Invalid or dateline-wrapped viewport geometry fails closed. The region list is read for display and never written by this helper. Its cost depends on the number of packs intersecting the viewport; downloaded packs and map assets remain in MapLibre's app-private store. See D-234-01.
