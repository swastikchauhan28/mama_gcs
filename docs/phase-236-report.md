# Phase 236 — view a completed saved map area

## Goal and scope

The owner approved a per-pack View saved area action in Maps settings. Baseline `05b35bd74c40f5df8963dd9bf742b2d79cd092e7`; older untracked `output/` demo files were preserved. No operator phone or hardware connection is required. See D-236-01.

Settings reads `OfflineFieldMaps.state`, which reflects MapLibre's native offline region metadata. A completed pack with valid bounds gets a View saved area action. The action passes only its ID through a dedicated map route; `VehicleMap` re-reads that pack, uses the existing Field map style for this view, and fits its rectangle after the native map is measured. The selected basemap preference is not written. Missing, deleted, incomplete or invalid packs produce an unavailable notice instead of a camera target. Existing offline viewport/zoom warnings remain authoritative.

The route ID is transient navigation data. Pack bounds and completion status remain in MapLibre app-private storage; the fit uses them in memory only. A normal online Field map can contact the existing OpenFreeMap destination for missing resources. A fitted view at zoom below 12 shows the existing zoom-range warning, because a whole-area view at that scale is not downloaded. This action does not certify tiles, survey the field or send a vehicle command. No dependency, credential, permission, schema or new destination is added.
