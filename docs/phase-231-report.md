# Phase 231 — bounded offline field maps

## Goal and scope

Add a downloadable vector basemap for the local plan area, with a clear completion state and a no-network display check. The user approved OpenFreeMap as the new tile source. This phase does not change saved missions, telemetry, vehicle commands or hardware. Baseline `de01a6e81cc5d6ba3d47693334b8d651b5201b64`; Phase 230 and older demo outputs were already uncommitted/untracked and were preserved.

## Execution path and data

`MamaGcsApp` passes the current local `MissionDraft` into Maps settings. `OfflineFieldArea.fromDraft` reads the keep-in outline, or route points when there is no outline. It pads the bounding rectangle, rejects missing, oversized and date-line-crossing inputs, and estimates Web Mercator tile coverage for zoom 12–18. It accepts at most 2,000 estimated tile coordinates, leaving room under OpenFreeMap's 3,000-tile download limit. The draft is read only; no vehicle coordinate is used for download.

The operator taps **Save current plan area**. `OfflineFieldMaps` creates or resumes a MapLibre offline region using the fixed OpenFreeMap Liberty style. The native offline database owns downloaded resources; a small in-memory state holds pack identifiers, names, bounds, byte/resource counts and completion. Up to five named packs are listed. Only a complete pack that contains the current plan area is labelled ready; opening the field-map style does not itself mark an area ready. The operator can remove a pack after confirmation without changing the draft. Offline-region metadata contains only a bounded draft name; the region definition stores its geographic bounds in the app's map database.

`MamaGcsApplication` keeps a unique app/version User-Agent and limits MapLibre to four parallel HTTP calls. During a user-started offline download, a network interceptor counts OpenFreeMap requests and response bytes, stopping before 2,800 requests or 45 MB. A second status check stops a region at 2,000 completed tiles or 45 MB. The offline definition excludes bulk ideograph glyphs. These limits apply to the OpenFreeMap host and are deliberately below its published 3,000-tile/50 MB download limits. They do not guarantee that a field can fit or that an incomplete region will render. `BasemapStyle.OFFLINE_FIELD` selects the same fixed style URL; MapLibre resolves downloaded resources from its offline database when network access is disabled. The map shows visible OpenStreetMap/OpenFreeMap attribution.

## Risks and next check

OpenFreeMap is a third-party service with no availability guarantee, and its terms can change. Its data is geographic context, not a surveyed field boundary or positioning source. A downloaded pack is limited to its bounds and zoom 12–18; other tiles can be blank offline. The current implementation does not background/resume downloads after process death; on returning to Maps settings it reads persisted region status and permits a retry. The owner should download the real field on Wi-Fi, verify **Ready offline**, then inspect that exact field with phone connectivity off before relying on it. Physical rover operation remains outside this phase. Review the network destination, quota enforcement, attribution, storage limits and downloaded-area wording before distribution.
