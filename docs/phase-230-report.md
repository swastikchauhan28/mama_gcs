# Phase 230 — Google map failure recovery

## Goal and scope

Give an operator a direct path from an unavailable Google map to the existing Maps settings. The app must leave the saved provider unchanged until the operator explicitly chooses another one. No telemetry, mission, command, account, permission, dependency or Google key handling changes are in scope. Baseline: `de01a6e81cc5d6ba3d47693334b8d651b5201b64` on `main`; older `output/` deliverables were already untracked.

## Design and execution path

`MamaGcsApp` supplies a navigation-only `LocalMapSettingsNavigation` callback to its map descendants. `GoogleVehicleMap` already classifies the configured-key and Play-services prerequisites and waits 20 seconds for tiles. It now selects one of three fixed `GoogleMapFailure` presentations and shows `Choose map provider`, which routes to the existing `map-settings` screen. The timeout state retains `Retry map`, which recreates only the Google `MapView`. Neither action writes a preference. `MapSettingsScreen` and the existing settings repository still own explicit provider changes.

The failure enum has three fixed labels and details; it holds no key, endpoint, map coordinate or telemetry data. It is not persisted. The navigation callback is UI-local and has no vehicle command capability. A MapLibre choice can also lack tiles if its own network or key is unavailable.

## Risk and recovery

The tile timeout cannot identify whether network, billing, Play services, key restrictions or Google service availability caused the failure. Synthetic notices do not prove real outage behavior. The local baseline revision is a recovery reference, not a production-qualified release. Reverting this change removes the shortcut without changing the saved provider; no data migration is needed. Review the navigation callback, failure copy, no implicit preference write and unchanged vehicle command path. The healthy disposable-emulator UI tests establish this focused display path only; other screen sizes and physical devices remain unverified.
