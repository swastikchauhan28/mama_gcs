## Decision and data path

The diagnostics screen receives `VehicleState.mavlinkDiagnostics` from the existing telemetry session. An explicit Start copies the session's start clocks and transport kind, plus the accepted selected-autopilot and inside/outside parser-rescan CRC candidate counters. A screen-local state machine compares subsequent snapshots using Android elapsed time. It freezes counter differences after at least 30 seconds. A closed/replaced session, regressed counter or inconsistent elapsed clock freezes an incomplete result without differences. Another explicit Start replaces the prior result; leaving the screen discards it. The display notes that the result is not a packet-loss measurement, proof of physical corruption, source authentication or vehicle readiness. See D-206-01.

The data structure is one baseline and one result with fixed-size scalar fields. It has no persistence, raw-message retention, export or external destination. The one-second screen tick can make the actual completion later than the target; the result shows observed elapsed milliseconds. The screen collects state updates and can miss brief intermediate changes.
