## Goal, path and decision

Goal: investigate two intermittent synthetic-test failures found in the 23 October regression without hiding defects. Input is fixture state in the Android test process; Compose lays out `HomePositionCard` in a scrollable `ScreenBody` and `VescBluetoothDiscoveryScreen` in a test activity; the tests inspect semantics and save a screenshot. [D-054-01](DECISIONS.md#d-054-01-stabilize-fixture-visibility-and-screenshot-evidence-without-relaxing-assertions) records the initial proposal and the dated reversal.

A fresh focused run later failed with `Failed waiting for PixelCopy!`; the edit was reverted because it was not a reliable replacement. The original test content assertions remain intact.
- No generic sleep/retry, ignored test, disabled assertion, production renderer change or command enablement remains. `git diff --exit-code --` against both test files returned 0 after reversal.
