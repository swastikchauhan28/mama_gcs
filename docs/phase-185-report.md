# Phase 185 — Select each affected route item

The Review card keeps one action per aggregated local warning. When a route warning lists several affected points or legs, that action opens a bounded-height lazy picker. Each row names the affected point or leg and the Route waypoint it focuses. A single-target warning still opens Route directly; an invalid-outline warning still opens Field outline. Cancel closes the picker without editing. The open picker is in-memory UI state keyed by the current draft, so a changed draft invalidates it.

The path is local draft → `MissionDraftReview.inspect` → at most five `MissionReviewIssue` rows, each with up to 250 one-based `MissionReviewTarget` entries → Review action → picker row → existing Route focus/scroll. The list is computed from the draft and is not persisted. The lazy picker composes visible rows only; the header text is truncated to two lines while the full warning remains on Review. No permission, dependency, schema, external destination, telemetry, upload or vehicle-command path changed. This remains a local drafting aid, not physical coverage or route-safety evidence.
