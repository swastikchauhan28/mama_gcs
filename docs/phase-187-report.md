# Phase 187 — Outline warning and numbered vertex jump

Review's outline warning now remains visible beside the Field outline controls. The user can enter a one-based vertex number from the current outline and jump to its highlighted row. Go sits beside the input so the portrait keyboard does not cover it; the keyboard's Done action uses the same jump handler. The jump changes only in-memory UI selection and scroll position. It never edits or saves a draft, identifies a culprit vertex, uploads a mission, or sends a vehicle command.

The path is the device-local `MissionDraft` → `MissionDraftReview.inspect` → current outline issue displayed in `MissionScreen` → bounded numeric input → stable vertex ID → the shared lazy editor's row. The list is at most 64 vertices. Input is limited to two characters and validated against the current count at click time. The selected ID is held in UI memory and invalidated when the ordered vertex-ID list changes; it is not persisted. `MissionScreen` owns this presentation state; `MissionDraftReview` owns the geometry observation, and the repository is untouched by a jump. No new dependency, permission, schema, external destination, telemetry or hardware operation was introduced. Baseline `790ae85`, clean worktree; see D-187-01.
