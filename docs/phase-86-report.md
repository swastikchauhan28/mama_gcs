# Phase 86 — Sampled main-field gaps on the selected map

Date: 2026-10-28. User approved sampled-gap visualization and emulator checks. Baseline `ed8a2bb6b4fd5d8e5693181fc251f5d9ddf1b5fa`, clean worktree. Model/version unavailable. See [D-086-01](DECISIONS.md#d-086-01-display-sampled-main-area-gap-centers-on-the-selected-coverage-map).

The estimator stores the centers that contribute to its existing unplanned-main sample count. A selected comparison preview projects them to geographic coordinates using the existing local projection; the UI passes them as one volatile MultiPoint in a separate MapLibre source/layer. Each preview holds at most 128² centers, so comparison can temporarily hold two bounded lists. Magenta dots show samples, not cell footprints, headland, exact gap boundaries or worked soil. The legend distinguishes samples, none detected and estimate unavailable, and warns gaps may be missed. Input changes, hide, outline changes and comparison regeneration clear the selection. Existing style/provider behavior remains; no new destination, data persistence, permission or vehicle command is introduced.
