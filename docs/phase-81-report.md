## Flow and boundaries

In Coverage, Compare directions produces independent previews. A successful card's Show on map action explicitly selects that direction; its local-plane pass centerline endpoints are inverse-projected from the same first-outline origin, radius and longitude scale used by the planner. The state owns a volatile bounded list of geographic line segments and the selected direction. VehicleMap renders it in its own cyan GeoJSON source and line layer with a preview-only legend, separate from orange saved-draft waypoints/route and the field outline. On narrow screens the map appears above Coverage when selected; the status suggests scrolling up and using Fit draft. Existing Fit draft includes both waypoints and outline, so distant waypoints can affect its framing. A local-style URL can be supplied to the mission screen for controlled offline UI fixtures; default behavior continues using the existing configured basemap.

Changes to outline or input, comparison recomputation, or Hide map preview clear the overlay; a style reload reinstalls the current source. No automatic selection, route write, upload, command or new network destination is introduced. The existing basemap configuration may contact its provider. Empty/invalid comparisons cannot select lines. Date-line-crossing fields are explicitly unavailable for overlay because the existing outline and fit logic are not validated across that boundary; diagram comparison still works. Geographic coordinates remain approximate planning geometry, not surveyed boundaries, turn paths, implement footprint, GPS accuracy or actual ploughed soil.
