# Phase 242: browse planned areas without rover GPS

## Goal and scope

The operator approved a software-only way to view saved field maps and planned routes from Operate while the Cube reports no GPS fix. The new **Browse planned areas** entry lists complete local offline map packs, the current working plan when it has a waypoint or complete outline, and saved library routes with geometry. A selected pack opens the existing saved-area viewer. A selected route opens a separate read-only map preview that fits its geometry, shows no live vehicle marker, and does not replace the working draft or upload a mission. The viewer explicitly distinguishes a planned area from the rover's position.

## Execution path and boundaries

`DashboardScreen.MapWorkspace` opens `map/browse` in `MamaGcsApp`. The browser reads `MissionPlanUiState` and refreshes `OfflineFieldMaps.state`; it applies the existing completed-pack boundary check before showing pack links. Current and library route destinations resolve the current plan state, with a missing library ID shown as unavailable. The route preview supplies an empty `VehicleState` and no waypoint edit callbacks to the existing `VehicleMap`. Both native and Google map renderers accept a one-time initial fit after their style and view size become ready. The selected basemap may still fetch its normal tiles; opening a completed saved pack uses the existing offline viewer. No new provider, permission, credential, persistent data, authentication rule or vehicle command path was added.

The existing local bounds remain in force: up to five saved packs, 25 library entries, 250 waypoints and 64 outline vertices. Browser selection is transient navigation state; storage remains owned by the existing map and mission modules. Incomplete packs and outlines under three vertices are not offered as areas. A removed route shows an unavailable message; a failed local plan load and an unavailable map style keep their existing recovery messages. Local titles are displayed with line and overflow bounds. A planned route is a reference, not evidence of rover position or field coverage.
