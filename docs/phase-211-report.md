# Phase 211 — Correct field-outline coordinate dialog title

## Goal and decision

The user approved this software-only local planning UI correction on 2026-11-20. Baseline `f34f326` on clean `main`; model/version unavailable. RC hardware work remained paused. See D-211-01.

`MissionScreen.openFenceEditor` selects a local outline vertex or opens a blank coordinate entry. The shared `WaypointDialog` previously received `outline = id != null`, so adding an outline vertex displayed `Add waypoint`, despite confirmation sending `MissionPlanAction.AddFenceVertex`. This could mislead an operator about which working-draft structure would change.

The outline call now always identifies the outline destination. The shared title chooses Add/Edit outline vertex or Add/Edit waypoint from `outline` and `editing`. The `MissionDraft` still holds at most 64 outline vertices and 250 route points; this phase adds no data structure, persistence, permission, network, dependency, external destination or vehicle command. The existing coordinate validation and `AddFenceVertex`/`EditFenceVertex` callbacks remain. An alternative separate outline dialog would duplicate validation and keyboard logic for a label correction.
