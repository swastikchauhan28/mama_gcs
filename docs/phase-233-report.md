## Design and flow

The separate OpenFreeMap Field map style refreshes MapLibre's app-private offline regions when opened. The map screen checks the current camera center and zoom against **complete** saved region bounds. It shows `NOT SAVED OFFLINE` if the center has no complete pack or the zoom is outside 12–18. It does not mask or erase cached pixels; it does not claim that an entire viewport or field is covered. The existing local planning overlays, map gestures, offline downloader, providers, network destinations, permissions, dependencies, secrets and vehicle-command boundary are unchanged. See D-233-01.
